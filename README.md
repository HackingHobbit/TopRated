# Top Rated Cards & Collectibles

Prototype online storefront for Top Rated Cards & Collectibles.

## What is included

- Static storefront app with routed sections for Home, Shop, Product Detail, Sell/Trade, About, Visit, and Owner Preview
- Database-shaped product data in `db/products.js`
- Search, filters, cart drawer, request form, offer form, and Clover checkout handoff placeholder
- Netlify-ready static hosting config in `netlify.toml`

## Local usage

Open `index.html` in a browser, or host the folder with any static file server.

## Future integrations

- Replace `db/products.js` with a real database-backed inventory API
- Connect cart checkout to Clover
- Add authenticated owner portal for product, stock, image, request, and offer management
